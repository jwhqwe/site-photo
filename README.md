# 현장 사진

건설 현장 사진에 도면 위치(핀)·찍은 부재·찍은 방향·이슈를 붙여 정리하는 개인용 웹앱입니다.

- 사진·영상·기록·도면은 모두 폰 안(브라우저 저장소)에만 저장됩니다. 서버로 보내는 기능이 없습니다.
- 이 저장소에는 앱 코드만 있습니다. 도면 파일과 사진은 들어 있지 않습니다.
- 도면은 앱의 "도면 파일 가져오기"로 폰에서 직접 넣습니다.
- 오프라인에서도 동작합니다(서비스 워커).
